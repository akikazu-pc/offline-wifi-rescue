# 发布形式、驱动升级与配置工具

台式机和笔记本是硬件覆盖分类。在线安装版和离线免安装完整版是交付形式。两个独立应用是「断网急救」主程序与 Microsoft Store 的「断网急救配置工具」。

| 发布形式 | 内容与用途 |
| --- | --- |
| 在线安装版 | 安装主程序，包内无驱动本体。联网时按需下载和安装，可导入事先准备的离线包 |
| 离线完整版（免安装） | 带已获分发授权的 Wi-Fi 驱动快照和本地索引，解包即可运行，首轮救援全程可断网。发布页明确列出覆盖日期、设备、系统及需自行准备的包 |
| Microsoft Store 配置工具 | 可独立查看本机设备和驱动状态、导出设备清单。装有主程序时可打开对应页面并管理联动设置 |

在线版可安装并与硬件测试联动。离线版从 U 盘或本地目录直接运行，不创建安装注册、托盘或自启动。两版共用程序版本，离线驱动快照另外编号。断网安装验证需包含运行时依赖。恢复联网后可以单独更新驱动索引及离线包。

## 驱动升级与回退

- 界面分开提供「补装缺失驱动」和「检查驱动升级」。升级时显示当前与候选的版本、日期、来源、适用设备、系统和已知变更。先核对 SUBSYS、OEM 适用性、扩展 INF 和 Windows 排名，再比较版本。用户可忽略某一版本。
- 自动检查可选，默认手动确认安装。可缓存完整候选包，校验 INF、哈希与签名后再安装。更新正在使用的网卡前，先缓存可恢复的旧驱动并提示可能短时断网。离线包也可比较已安装驱动与本地候选。
- 记录旧驱动、实际绑定的新驱动及重启状态。验证失败时提供可用的回退入口，回退后复查设备和联网。旧驱动无法备份或需要重启时，界面显示实际限制。网络中断后可用本地缓存恢复。

## 联动界面与托盘

- 主程序提供驱动安装、升级、备份、历史及设置。配置工具与主程序采用相同导航语义，双方都安装时，可直接打开对方对应页面，并显示统一的状态和设置入口。对方缺失时显示官方获取入口，Store 端的链接和外部依赖按上架政策验证。
- **每个 Windows 登录会话最多一个后台常驻实例和一个托盘图标。** 主程序独占托盘及自启动注册。配置工具作为前台入口，共用主程序状态，不单独注册常驻任务。安装或升级两个应用、重复启动和登录时均验证只有一个托盘。提权安装由短时任务执行。
- 用户可独立设置登录时启动、关闭窗口时最小化到托盘和自动检查更新。建议默认关闭开机启动及后台检查。托盘可打开主界面、查看状态、打开设置或退出。
- 两个应用通过受限的本地接口交换状态和导航请求。驱动安装由主程序显示设备及来源、取得用户确认后发起。测试同时启动、安装顺序互换、卸载其中一个、退出托盘、重启资源管理器，以及关闭自启后的重新登录。

Store 提审前需验证 MSIX 与桌面主程序的联动，以及涉及外部依赖和推荐链接的政策要求。参考 [Microsoft Store 政策](https://learn.microsoft.com/windows/apps/publish/store-policies)、[Windows 应用单实例](https://learn.microsoft.com/en-us/windows/apps/develop/launch/multi-instance-apps)、[应用能力声明](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/app-capability-declarations)。

## 评审后的发布与恢复验收

应用、驱动索引和离线快照分别编号，并声明兼容范围。升级正在使用的网卡前，完整缓存新包、可恢复的旧包及依赖，记录设备实例、原绑定 INF 和安装进度。旧包无法恢复时默认保留现用网卡。重启后核对实际绑定与连网状态。互联网探测单独失败时，先展示本地接入状态，由用户决定后续操作。回归覆盖下载中断、源文件撤下、Windows 拒绝绑定、需重启及回退后只连到本地接入点的情形。

启用托盘驻留且主程序运行时，每个交互式登录会话恰好显示一个图标。关闭驻留或主动退出后图标消失。退出时若正在安装，先显示任务状态并允许等待完成或在可安全中断时停止。主程序通过单实例机制拥有托盘。跨应用接口按当前用户授权，外链只用于导航，安装由主程序显示已校验的方案并单独请求提升权限。验证不同 Windows 用户隔离、更新后的单份启动注册和资源管理器重启后的单图标恢复。

先用最小 MSIX 原型验证商店配置工具与桌面主程序的互相打开、状态访问、双装及卸载，再核查 Partner Center 的送审要求。主程序提供完整的本地配置页。

## 与硬件测试联动

硬件测试使用现有的 hardware-check 桌面项目。两款应用各自安装、启动和卸载。双装时，通过共享窗口打开对应页面，并在每个登录会话中共用一个托盘入口。联动边界与原型验收见[两款桌面应用的安装与联动](shared-desktop-apps.md)。
