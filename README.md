# 断网急救 · Offline Wi-Fi Rescue

面向 Windows 10 / Windows 11 的开源 Wi-Fi 驱动急救工具。目标是在重装系统后，用 U 盘恢复无线联网。

**状态：项目立项。当前仓库提供产品设计和调研，尚无可执行程序或离线驱动包。**

| 版本 | 目标设备 | 选包依据 |
| --- | --- | --- |
| 断网急救 · 台式机版 | AM4、AM5、LGA1700、LGA1851 组装机，兼顾后装 PCIe 无线网卡 | 硬件 ID、子系统 ID、系统版本和架构，结合主板型号及修订版 |
| 断网急救 · 笔记本版 | 各品牌 Windows 笔记本，首发目标为 Windows 10/11 x64 | 硬件 ID、子系统 ID、系统版本和架构，结合 OEM 机型及扩展 INF |

两款共用识别、索引、校验和安装引擎，使用独立的驱动包目录。四个平台的全品牌、全型号覆盖是长期目标。覆盖状态将按硬件 ID、Windows 构建和实机验证结果公开。

详见[调研与首版设计](docs/research.md)。

代码采用 MIT 许可。第三方驱动各自适用其发布方的许可条款。
